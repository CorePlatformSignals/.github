# Core Platform Signals organization defaults

This repository contains organization-wide GitHub configuration and the public organization profile.

## Contents

- `profile/README.md`: public organization profile
- `CONTRIBUTING.md`: contribution and engineering workflow
- `SECURITY.md`: coordinated vulnerability disclosure policy
- `CODE_OF_CONDUCT.md`: contributor conduct expectations
- `.github/ISSUE_TEMPLATE/`: shared issue forms
- `.github/PULL_REQUEST_TEMPLATE.md`: shared pull request checklist

Product code does not belong in this repository.
