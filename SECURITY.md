# Security Policy

## Reporting a vulnerability

Do not disclose security vulnerabilities in public GitHub issues, discussions, or pull requests.

Report vulnerabilities privately to the organization owners. Include:

- affected component and version
- reproduction steps
- impact assessment
- known mitigations
- logs or proof-of-concept material with sensitive values removed

## Scope priorities

Reports involving tenant isolation, authentication, authorization, secret exposure, event forgery, policy bypass, evidence tampering, model prompt injection, webhook signing, or metering manipulation are treated as high priority.
